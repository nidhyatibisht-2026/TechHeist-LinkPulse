# Deploying to Antideploy

LinkPulse runs as two Antideploy applications:

| App | Folder | Address | What it is |
|---|---|---|---|
| API | `backend/` | https://lnkp.antideploy.app | FastAPI: the REST API and the short links themselves |
| Dashboard | `frontend/` | https://linkpulse.antideploy.app | React app, built as a static site |

The free plan allows one live server app, and static sites don't count against that, so this fits.

**What the platform provides:**
- **PostgreSQL:** the `DATABASE_URL` variable is set by Antideploy.
- **`SECRET_KEY`:** generated by Antideploy, and stable across deploys.

**What's not used:**
- **Redis:** the API runs with `REDIS_URL=none`, so there's no cache and no worker. Clicks are written right after each response. Everything else works the same.

## One-time setup (already done for this project)

1. Log in once. The Antideploy device login stores an account token in `~/.antideploy/config.json`. That file never goes in the repo.
2. The two applications exist, and their ids are in `backend/.antideploy.json` and `frontend/.antideploy.json`. Those files hold no secrets and are safe to commit.

## Deploy

```bash
./deploy/antideploy.sh api    # backend
./deploy/antideploy.sh web    # frontend
./deploy/antideploy.sh all
```

The script uploads each folder without `.env`, `.venv`, `node_modules`, `dist` or local `*.db` files. It also sets the API's variables:
- `BASE_URL` and `FRONTEND_URL`
- `TRUST_PROXY_HEADERS=true`
- `REDIS_URL=none`

The free plan allows 10 successful server deploys a month. Static deploys (the dashboard) and failed builds are free.

## Seed the demo data

Run this once, against the hosted database:

```bash
cd backend
# put the hosted DATABASE_URL in backend/.env first (never commit it)
python -m scripts.seed --reset
```

`--reset` wipes the tables. Only run it before the app holds real data.

## When something breaks

Open the app in https://antideploy.com/console and check:
- the deploy history: its `error` line says why
- the logs

The most common failure is an app that builds but never listens on `$PORT`. The backend Dockerfile already uses `${PORT:-8000}`.

You can revoke the Antideploy login at any time at https://antideploy.com/tokens.
